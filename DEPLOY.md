# Деплой HoReCa Чеклист на Railway

## Что такое Railway

Railway — это облачная платформа для деплоя приложений. Бесплатный trial даёт $5 кредитов — этого хватит на несколько недель тестирования.

---

## Шаг 1: Регистрация

1. Зайди на https://railway.app
2. Нажми **"Login"** → войди через **GitHub** (проще всего)
3. Подтверди email, если попросят

---

## Шаг 2: Загрузи код на GitHub

Если репозиторий уже на GitHub — переходи к шагу 3.

Если нет — создай репозиторий на GitHub и запуши код:

```bash
git remote add origin https://github.com/ТВОЙ_ЮЗЕР/ТВОЙ_РЕПО.git
git push -u origin main
```

---

## Шаг 3: Создай проект на Railway

1. На дашборде Railway нажми **"New Project"**
2. Выбери **"Deploy from GitHub Repo"**
3. Найди и выбери свой репозиторий
4. Railway автоматически определит Python-проект и начнёт деплой

---

## Шаг 4: Добавь базу данных PostgreSQL

1. В проекте нажми **"New"** → **"Database"** → **"Add PostgreSQL"**
2. Railway создаст базу и автоматически добавит переменную `DATABASE_URL`
3. Проверь: зайди в свой сервис → вкладка **"Variables"** → там должна быть `DATABASE_URL`

---

## Шаг 5: Настрой переменные окружения

Зайди в сервис (не в базу, а в своё приложение) → вкладка **"Variables"** и добавь:

| Переменная | Значение | Обязательно? |
|-----------|---------|-------------|
| `SECRET_KEY` | Любая длинная случайная строка (например: `my-super-secret-key-12345`) | Да |
| `PORT` | `5000` | Нет (Railway обычно сам задаёт) |

---

## Шаг 6: Проверь настройки деплоя

Ничего настраивать не нужно — файл `nixpacks.toml` в корне репозитория уже содержит все настройки сборки и запуска. Railway подхватит его автоматически.

---

## Шаг 7: Генерация домена

1. Зайди в сервис → **"Settings"** → секция **"Networking"**
2. Нажми **"Generate Domain"**
3. Railway даст тебе URL вида `https://твой-проект.up.railway.app`
4. Открой этот URL в браузере — приложение должно работать!

---

## Шаг 8: Первый вход

Приложение автоматически создаёт тестовые аккаунты:

| Логин | Пароль | Роль |
|-------|--------|------|
| `admin` | `admin123` | Администратор |
| `manager` | `manager123` | Менеджер (исполнитель) |

> **Важно:** для реальной работы смени пароли!

---

## Что дальше: деплой на свой хостинг

Когда будешь переносить на свой сервер, код менять не нужно. Просто:

1. Установи Python 3.11+ и pip
2. Установи PostgreSQL (или используй SQLite — по умолчанию)
3. Склонируй репозиторий
4. Установи зависимости:

```bash
cd backend
pip install -r requirements.txt
```

5. Задай переменные окружения:

```bash
export SECRET_KEY="твой-секретный-ключ"
export DATABASE_URL="postgresql://user:password@localhost:5432/horeca"
# Или не задавай DATABASE_URL — тогда будет SQLite
```

6. Запусти:

```bash
gunicorn app:app --bind 0.0.0.0:5000
```

## Устранение проблем

**Деплой падает с ошибкой?**
- Проверь логи: в Railway зайди в сервис → вкладка **"Deployments"** → нажми на последний деплой → **"View Logs"**

**Приложение не открывается?**
- Убедись, что сгенерировал домен (шаг 7)
- Проверь, что `DATABASE_URL` привязана к сервису (шаг 4)

**Ошибка с базой данных?**
- Убедись, что PostgreSQL-сервис запущен
- Проверь, что переменная `DATABASE_URL` видна в Variables сервиса
