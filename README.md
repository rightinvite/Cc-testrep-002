# HoReCa Чеклист

Веб-приложение для управления чеклистами в сфере HoReCa (отели, рестораны, кафе).

## Возможности

- **Чеклисты** — создание, выполнение, сброс отметок
- **Шаблоны** — готовые шаблоны для типичных задач HoReCa
- **Конструктор** — визуальный конструктор с готовыми компонентами (кухня, зал, бар и т.д.)
- **Журнал действий** — логирование всех отметок и сбросов
- **Роли** — администраторы и исполнители
- **Назначение** — можно назначать чеклисты конкретным исполнителям

## Готовые шаблоны

- Открытие ресторана — утренний чеклист
- Закрытие ресторана — вечерний чеклист
- Тайный покупатель — проверка ресторана
- Проверка кухни — санитарные нормы
- Открытие отеля — утренняя смена ресепшн
- Инвентаризация бара

## Запуск

```bash
cd backend
pip install -r requirements.txt
python app.py
```

Приложение запустится на http://localhost:5000

## Демо-доступ

| Логин   | Пароль      | Роль         |
|---------|-------------|--------------|
| admin   | admin123    | Администратор |
| manager | manager123  | Исполнитель   |

## Технологии

- **Backend:** Python, Flask, SQLAlchemy, SQLite
- **Frontend:** HTML, CSS, JavaScript (без фреймворков)
